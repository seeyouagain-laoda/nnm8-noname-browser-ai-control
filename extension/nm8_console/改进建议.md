# NM8 控制台 — UX 改进建议

> 聚焦「加强用户体验」的具体方面。每条给出：痛点 → 建议 → 落地成本 → 状态。
> 状态图例：✅ 已落地 ｜ 🔜 计划 ｜ 💡 建议（待排期）

---

## 一、当前体验痛点速览

1. **控制台「只看不能点」**：面板实时刷新全场状态，但除顶部几个按钮外，绝大多数信息不可交互，新手不容易把「看到的状态」和「能下发的指令」对应起来。
2. **自动驱动黑盒**：早前自动驱动偶发卡死（引擎内容包 bug），用户毫无感知，只能干等。
3. **接口门槛高**：虽有 `NM8.help()`，但缺乏「场景化向导」，新手不知道先敲哪条。
4. **日志/错误散落**：行为日志在 `lib.video`、内部操作日志在 `NM8.log2()`、引擎异常在 `/errors`，三处分散。
5. **浮层位置固定**：停靠右上，小屏或某些将皮肤局可能遮挡原生顶栏。

---

## 二、具体改进建议（按性价比排序）

### 1. 🔜 卡死「健康灯」+ 自恢复提示
- **痛点**：自动驱动若停滞，用户只能靠轮询 `/state` 发现。
- **建议**：面板顶部加一个常驻色块——绿=正常推进、黄=看门狗已介入挽救、红=已吞 N 个引擎异常（`NM8.state.errorCount`）。
- **成本**：低（已有 `errorCount` / 看门狗计数，渲染到面板即可）。
- **理由**：让「容错续推」这件事对用户可见、可安心。

### 2. ✅ 场景化快捷指令（已实现核心）
- 面板已提供「接管 / 自动 / 刷新 / 隐藏」+ 加血/扣血/发牌/神装/复活/秒杀等一键按钮。
- **后续**：把常用组合再固化成「一键开始 5 人局」「一键全员神装」「一键和解」三个宏按钮。

### 3. 💡 实时对局时间线（可点击复盘）
- **建议**：把 `NM8.log.tail()` 的行为事件渲染成竖向时间线，每条可点开看 `content` 详情，点某条可「跳转/标记」用于复盘。
- **成本**：中（需前端渲染，但数据现成）。
- **理由**：直接呼应「官方录像」能力，把「读日志」升级成「看时间线」。

### 4. 🔜 新手引导向导（首次进入 3 步）
- **建议**：首次进入对局弹 3 步浮层：① 点右上「控制台」展开面板 → ② F12 输入 `NM8.help()` 看接口 → ③ 试 `NM8.quickStart()` 一键接管+自动跑。
- **成本**：低（localStorage 记 `nm8_onboarded`）。
- **理由**：把「文档」前置成「引导」，显著降低上手门槛。

### 5. 💡 一键导出对局 JSON
- **建议**：面板加「导出」按钮，把 `NM8.video()` 的官方录像 JSON 下载为文件，或调用 `/api/v1/fieldlog` 落盘的 jsonl 直接下载。
- **成本**：低。
- **理由**：方便把对局交给其他 AI 训练/复盘，呼应「实时日志供其他 AI 读取」的定位。

### 6. 🔜 异常聚合面板
- **建议**：面板单独开一个「异常」分组，把 `/errors`（含 `engineError`）标红列出，点击可复制原始堆栈。
- **成本**：低（数据已有）。
- **理由**：`ignore_error` 让游戏不卡死，但「哪里出错了」必须让用户一眼看到，否则等于把 bug 藏起来。

### 7. 🔜 面板位置记忆
- **建议**：拖拽后把位置存入 `localStorage`，下次进入恢复；默认停靠右上但不遮挡原生顶栏（`top:46px` 起）。
- **成本**：低（已有拖拽，加持久化）。

### 8. 💡 主题跟随系统
- **建议**：读 `prefers-color-scheme` 切换面板明/暗；当前固定暗色毛玻璃。
- **成本**：低。

### 9. 💡 快捷键可配置
- **建议**：F9 切换面板改为可配置（如 `~` 或自定义），避免与游戏原生快捷键冲突。
- **成本**：低。

### 10. 💡 多语言 i18n
- **建议**：面板与 `help` 文本抽成 `i18n` 字典，支持中文/英文切换。
- **成本**：中。

## 三、已采纳并落地的建议（本仓库）

| 建议 | 版本 | 说明 |
|---|---|---|
| 引擎容错 `ignore_error` + 全局错误捕获 | v3.4.0 | 自动驱动不再因内容包 bug 卡死，异常仍可见（`/errors` 含 `engineError`） |
| 看门狗自动恢复 | v3.1.0+ | 步骤停滞 6s 起循环升级挽救 |
| 悬浮面板 + F9 + 启动器常驻 | v3.0.0+ | 不依赖 F12 也能用 |
| 一键快捷指令按钮 | v3.0.0+ | 加血/扣血/发牌/神装/复活/秒杀等 |
| 实时行为日志复用官方 `lib.video` | v3.3.0 | 零副作用、供其他 AI 读取 |

---

## 四、优先级小结

- **立刻做（低成本高收益）**：① 健康灯 ⑥ 异常聚合 ④ 新手向导 ⑦ 位置记忆。
- **排期做（中成本）**：③ 时间线 ⑩ i18n。
- **锦上添花**：⑧ 主题 ⑨ 快捷键配置 ⑤ 导出。

> 这些建议与「后续学习编写武将/技能/卡牌」正交：控制台负责「观测与操控」，内容创作负责「扩展玩法」，二者通过同一套 `NM8` / 官方 API 衔接。
